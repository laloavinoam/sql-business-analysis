# SQL Business Analysis

## 📊 Project Overview

This project demonstrates my SQL and business analysis skills using a restaurant business dataset.

The dataset was designed and built with the assistance of **AI**, and AI was used throughout the project as a development and learning assistant.

The project focuses on analyzing customers, restaurants, orders, payments, and revenue to identify useful business insights.

---

## 🎯 Key Analysis

- Restaurant Performance & Revenue
- Customer Spending Analysis
- Customer Segmentation
- Monthly Revenue Trends
- Top Customers by Restaurant
- First vs. Last Order Analysis

## 🤖 AI-Assisted Analytics

AI was used throughout the project as a **development and learning assistant**.

I used AI to:

- Build and structure the initial dataset

## 💡 Business Perspective

The project focuses not only on writing SQL queries, but also on understanding **what the data means from a business perspective**.

The analysis can help identify:

- High-value customers
- Restaurant revenue performance
- Changes in monthly revenue
- Customer purchasing patterns
- Differences between first and last orders
